Last updated: October 30, 2026

Draft for the supplied self-hosted beta. Review against actual hosting, logging and retention before publishing.

Document processing

PDF pages render in the browser. Original-text detection, permanent replacement and processed previews send PDF data to the Python server running this installation. The included server processes PDF data in memory and does not intentionally save uploaded PDFs to disk.

Local recovery

Project recovery may be saved in browser local storage. Use Clear recovery or browser settings to remove it.

Server logs and third parties

The server logs requests and errors to its console. Hosting providers may log more information. The editor loads JavaScript libraries from public CDNs, which receive connection metadata.
